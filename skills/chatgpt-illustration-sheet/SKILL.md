# Illustration sheets drawn by ChatGPT

## Rules

- **ChatGPT draws the illustrations.** You write the prompt; the user pastes it into ChatGPT and
  saves the image. Do not substitute stock pictures, emoji sets (Fluent, Noto), icon fonts or
  pictures from other decks, and do not call an image API unless the user sets one up and asks.
- **Many per generation, never one.** Every prompt asks for a sheet of 4 to 9 illustrations, 6 by
  default (3 × 2). If the deck needs fewer, add the next ones it is likely to need (the other
  programmes, sections or steps) so the sheet is full. One sheet = one generation = one style.
- **One style per deck.** Pick one preset from `styles.json` (or write one) and use it for every
  sheet of the deck, so all illustrations look like one family.
- **Talk to the user in their language;** the prompts stay in English, which generators follow best.

## Workflow

### 1. List what the deck needs

One line per illustration: a short `key` (file name, a-z and dashes) and a `subject` that names
**two to four concrete objects** grouped into one scene, in the programme's own terms:

- good: "a cluster of blue office buildings; in front a yellow construction helmet, a wrench with a
  gear, and a clipboard with green check marks"
- weak: "project management" (abstract, so the generator invents something generic)

Keep words out of the pictures. If a word really helps (a tab reading "L1"), ask for one short
word; generators misspell longer text.

Write the list to a spec file, for example `prompts/spec.json` in the project:

```json
{ "style": "glossy-3d", "cols": 3, "max": 6,
  "items": [ { "key": "prime", "subject": "..." }, { "key": "ed", "subject": "..." } ] }
```

`max` is illustrations per sheet: 6 by default, up to 9 for small icons. Fewer per sheet gives each
illustration more pixels (see the table below).

### 2. Write the sheet prompts

```bash
SKILL=<path to this skill>
python3 $SKILL/scripts/sheet_prompt.py prompts/spec.json prompts
```

It spreads the items over the fewest sheets and writes, per sheet, `sheet-NN.prompt.txt` (the text to
paste) and `sheet-NN.json` (what the slicer needs). Give the user the prompt text in a code block
and these instructions:

1. Open ChatGPT, paste the whole prompt of one sheet as one message.
2. If the result is not complete (an illustration cut off, two touching, the wrong number), ask
   ChatGPT in the same chat to redraw with more space between illustrations.
3. Download the image and save it as `<library>/sheets/sheet-NN.png`
   (default library: `assets/generated/` in the project).

Several sheets can go in the same ChatGPT chat one after another; that keeps the style close.

### 3. Cut the sheet

```bash
python3 $SKILL/scripts/slice_sheet.py assets/generated/sheets/sheet-01.png prompts/sheet-01.json assets/generated
```

It finds the empty gutters between rows and between illustrations, cuts each one out, makes the
background transparent and trims it, then writes `assets/generated/<key>.png`, records it in
`assets/generated/library.json` (key, subject, style, sheet, size, date) and saves
`preview-sheet-NN.png`.

Open the preview. Each illustration is shown on a light and on a blue card. Check:

- the number and order match the list (the slicer reads row by row, left to right);
- nothing is cut off and no neighbour leaks in;
- no white rim on the blue card, and no white part of the picture eaten away. A white background
  is cleared from the edges inwards, so a white object touching the edge can lose a bit; a
  transparent sheet avoids this, so ask ChatGPT for a transparent PNG first;
- the style matches the rest of the deck.

If one or two illustrations are wrong, do not redraw them alone: write a new sheet with those
items plus the next illustrations the deck will need, so the sheet stays full.

### 4. Use them

The PNGs are transparent and trimmed, ready to place:

- in a `pptx-varied-deck` deck: as the `image` of an item, node, card or table cell;
- in a hand-written pptxgenjs `build.js`: place `assets/generated/<key>.png` contain-fit in its box
  (keep the aspect ratio; never stretch);
- elsewhere: as any PNG.

Before making new ones, look in `library.json`: a key that already exists in the same style is reused.

## Sizes

ChatGPT draws at 1024 × 1024, 1536 × 1024 or 1024 × 1536; the prompt picks the shape of the grid.

| Sheet | Pixels per illustration | Largest on a slide at about 220 dpi |
|---|---|---|
| 2 × 2 (4) | about 500 | about 2.3 in, a hero picture |
| 3 × 2 (6), default | about 480 | about 2.2 in, card and step pictures |
| 3 × 3 (9) | about 320 | about 1.5 in, chips and small icons |

An illustration shown larger than its row allows looks soft; use a sheet with fewer cells for it.

## Notes

- Check the company's rules and OpenAI's terms before using generated pictures outside the company.
- `styles.json` holds the presets. `glossy-3d` is a glossy corporate 3D look: royal blue and white
  with small green, yellow and red accents, two to four objects per scene; `glossy-3d-energy` leans
  green and solar yellow. Add a new preset rather than editing one that existing decks already use.
